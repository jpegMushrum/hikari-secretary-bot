# Документация бота

Hikari Secretary работает вместе с Go backend, PostgreSQL и административной
miniapp. Участники пользуются ботом; администраторы могут работать в чате
или в панели.

| [Черновики и miniapp](miniapp-handoff.md) | Отправка сообщения боту, предпросмотр и настройка публикации |
