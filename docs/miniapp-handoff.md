# Продолжение черновика в Mini App

Отправьте или перешлите материал в личный чат с ботом. Бот создаст черновик
в backend. Дальше можно выбрать цели, настроить регистрацию и опубликовать
материал сразу или по расписанию в чате либо открыть тот же черновик кнопкой
«Продолжить в панели».

Если задан `MINIAPP_URL`, кнопка в черновике открывает `/admin/publications/{id}`,
а персональная кнопка Telegram «Панель клуба» — `/admin/events`. Обе доступны
администраторам. Backend проверяет подпись Telegram `initData` и роль
администратора; одного ID черновика для доступа недостаточно.

`MINIAPP_URL` — адрес HTTPS без пути, query, fragment и учётных данных. В
production Compose собирает его из `MINIAPP_DOMAIN` и `MINIAPP_HTTPS_PORT`.
Локальный Compose запускает тестового бота с отключёнными кнопками miniapp;
панель открывается отдельно в браузере по адресу [localhost:5173](http://localhost:5173).

В miniapp можно просмотреть исходный материал, настроить мероприятие и цели,
опубликовать сразу или по расписанию. Исходные Telegram entities и Rich Message
доступны только для просмотра.

Для предпросмотра бот сохраняет копии фотографий в `MEDIA_DIR`. Backend читает
их из общего каталога. `BOT_MEDIA_DIR` позволяет указать backend
дополнительный путь поиска. По умолчанию оба контейнера видят файлы в
`/app/data/media`, смонтированном с хоста. При отправке Rich Message используются
исходные Telegram file IDs. Если скачивание копии не удалось, бот записывает
предупреждение и продолжает обработку материала. Фото сохраняются для истории
и после отмены или отправки публикации.
