# AI-материалы для разговорного клуба

Backend может готовить ежедневные материалы для разговорного клуба через DeepSeek,
а бот предоставляет администратору интерфейс и доставляет готовую публикацию:
тему разговора, вопросы, тематическую лексику и грамматические конструкции.

## Включение

Для production укажите в корневом `.env` ключ и целевую площадку из
`targets.json`. Compose передаст параметры генерации backend. Ключ цели нужен
и боту для ручной генерации. Локальный Compose отключает ИИ.

```dotenv
DEEPSEEK_API_KEY=...
AI_TOPIC_TARGET_KEY=club_topic
```

Чтобы включить ежедневную автоматическую публикацию, задайте время в часовом
поясе `TIMEZONE`:

```dotenv
AI_TOPIC_AUTO_PUBLISH_TIME=12:00
```

При пустом `AI_TOPIC_AUTO_PUBLISH_TIME` доступна ручная генерация в меню
бота, если настроены ключ DeepSeek и цель.

Количество вопросов, слов и грамматических конструкций настраивается в `.env`:

```dotenv
AI_TOPIC_QUESTION_COUNT=5
AI_TOPIC_VOCABULARY_COUNT=10
AI_TOPIC_GRAMMAR_COUNT=3
```

## Ручная подготовка

В разделе «ИИ» выберите JLPT от N5 до N1, при необходимости нажмите
«Добавить комментарий», затем «Сгенерировать тему». В предпросмотре можно
выбрать «Перегенерировать», «Опубликовать» или «Отменить». После нажатия
«Опубликовать» материал попадает в очередь и историю.

Для запланированной темы в «Очереди» доступны «Предпросмотр», «Исправить»
и «Перегенерировать». Замена обновляет материал в истории и сохраняет время
отправки.

## Автоматическая подготовка

Планировщик backend создаёт задание в PostgreSQL и ставит сгенерированный
материал в очередь на заданное время. После наступления этого времени он
создаёт следующее задание на завтра, а при позднем запуске также обрабатывает
пропущенную публикацию за сегодня. После ошибки backend повторяет попытку с
увеличивающейся задержкой. При окончательном сбое генерации бот отправляет
уведомление администраторам.

Если ответ DeepSeek обрывается по длине, backend повторяет запрос с просьбой
сохранить структуру и сделать материал короче.

## Разнообразие материалов

При подготовке следующей темы backend учитывает материалы, успешно
поставленные в очередь:

- заголовок темы разговора и тема лексики — жёсткая защита от точного повтора;
- японские слова и грамматические паттерны из 14 последних материалов — мягкий
  ориентир для следующей генерации.

Модель старается выбирать новые слова и конструкции, но повтор не запрещается,
когда он уместен для обучения. Отдельная таблица истории в miniapp показывает
задания генератора во всех состояниях, включая ожидающие, отменённые и ошибочные.
