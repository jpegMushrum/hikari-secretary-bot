# Hikari Secretary · Telegram Bot

Telegram-компонент [платформы Hikari Secretary](https://github.com/jpegMushrum/hikari-secretary).
Информация о клубе, возможностях платформы, версиях и запуске находится
в основном репозитории.

## Ответственность

- Команды, кнопки и диалоги участников и администраторов.
- Приём сообщений и создание черновиков через backend.
- Доставка публикаций, напоминаний и уведомлений в Telegram.
- Персональная кнопка «Панель клуба» и переход из черновика в miniapp.

Стек: **Python 3.12, aiogram**. Данные и бизнес-правила принадлежат Go backend;
бот использует внутренний API и не подключается к PostgreSQL напрямую.

## Разработка

Бот запускается в составе платформы через корневой
`docker-compose.bot-local.yml` или `docker-compose.production.yml`.
По умолчанию контейнер бота читает корневой `.env`. В production можно
выбрать другой файл для контейнера через `BOT_ENV_FILE`.
