# Hikari Secretary Bot

![Версия](https://img.shields.io/badge/version-v0.9.0-6A5ACD)
![Python](https://img.shields.io/badge/Python-3.12-3776AB?logo=python&logoColor=white)
![Docker](https://img.shields.io/badge/Docker-Compose-2496ED?logo=docker&logoColor=white)
![Статус](https://img.shields.io/badge/status-beta-F59E0B)

Telegram-секретарь клуба японского языка **Hikari ITMO**. Бот помогает команде
планировать публикации, проводить мероприятия и поддерживать общение с
участниками — без ручных таблиц и переписки в нескольких чатах.

[Открыть канал Hikari ITMO](https://t.me/Hikari_ITMO) · [Открыть бота](https://t.me/hikari_secretary_bot)

> Текущая версия: **v0.9.0** · Статус: **beta**

> Пока `bot/` ещё обычный каталог родительского репозитория, рабочие `.env`,
> `targets.json` и `data/` остаются уровнем выше. Запускайте его из корня:
> `docker compose -f bot/docker-compose.yml up -d --build`. После выделения в
> самостоятельный репозиторий передайте пути через `BOT_ENV_FILE`,
> `BOT_DATA_DIR` и `BOT_TARGETS_FILE` либо используйте будущий интеграционный
> Compose в корне платформы.

## Что умеет

- Планирует и публикует тексты, ссылки, фотографии, альбомы и Telegram Rich
  Messages в каналы, чаты и топики супергрупп.
- Создаёт мероприятия с регистрацией, профилями участников, напоминаниями,
  отметкой посещения и отменой записи.
- Показывает администраторам таблицы участников, отзывов и статистики людей.
- Собирает обратную связь после подтверждённого посещения и из пользовательской
  панели.
- Готовит и по расписанию публикует материалы для разговорного клуба: тему,
  вопросы, лексику и грамматику выбранного уровня JLPT.

## Технологии

- Python 3.12 и aiogram;
- SQLite и версионированные миграции с резервной копией;
- Docker Compose;
- DeepSeek API — опционально, для AI-материалов.

## Границы текущей версии

В `v0.9.0` поддерживается Telegram. Намеренно не входят видео и документы,
опросы, регулярные публикации общего назначения, редактирование и массовое
удаление уже опубликованных сообщений, экспорт таблиц и внешняя статистика
публикаций.

Администрирование пока выполняется в личном чате с ботом. Веб-панель и переход
на PostgreSQL — следующее направление развития, но не часть текущего релиза.

## Версионирование

Проект следует [Semantic Versioning](https://semver.org/lang/ru/). Пока версия
находится в ветке `0.x`, новые возможности могут сопровождаться изменениями
конфигурации и интерфейсов. Перед обновлением production-экземпляра создавайте
резервную копию `data/` и читайте заметки релиза.

## Безопасность данных

Не публикуйте `.env`, рабочий `targets.json` и содержимое `data/`. В них могут
быть токены сервисов, приватные Telegram ID и персональные данные участников.
